# الغرس

مختبر استشراف المستقبل الإماراتي: منصة تفاعلية لاستشراف مستقبل المجتمع والاقتصاد الإماراتي حتى 2071.

## النشر على Cloudflare Pages

- Framework preset: None
- Build command: اتركه فارغاً
- Build output directory: `public`

## المنهج

- ستة محركات رئيسية. التعليم ومشاركة المواطنين في القطاع الخاص تغذّي محور الجاهزية، والذكاء الاصطناعي والإنتاجية تغذّي محور التحول التقني، والأسرة والتركيبة السكانية عناصر اجتماعية شبه ثابتة.
- أربعة سيناريوهات من تقاطع المحورين: النخلة الباسقة، الفجوة، الطاقة الكامنة، الراحة الخادعة.
- خيارات قرار ترفع المحركات المرتبطة بها عند تطبيقها، فيتغيّر السيناريو والآثار المتوقعة.

## تنبيه

الأرقام والآثار ودرجة الاقتراب ناتجة عن نموذج توضيحي، وليست بيانات رسمية. تُعاير لاحقاً على خط الأساس من المصادر الرسمية.
